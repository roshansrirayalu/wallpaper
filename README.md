# Wallpaper 🖼️

A simple wallpaper browsing website with multiple categories and dedicated pages for exploring different wallpaper styles.

## ✨ Features

- Multiple wallpaper categories
- Anime wallpapers
- Gaming wallpapers
- Minimalist wallpapers
- Natural wallpapers
- Night wallpapers
- Pattern wallpapers
- Additional category pages
- Sign-in and sign-up pages
- Simple visual browsing experience

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 📁 Project Structure

The project is organized into separate pages for different wallpaper categories and user-facing sections.

Examples include `anime.html`, `gaming.html`, `minimalist.html`, `natural.html`, `night.html`, `pattern.html`, plus sign-in and sign-up pages.

## 🚀 Run Locally

`git clone https://github.com/roshansrirayalu/wallpaper.git`

`cd wallpaper`

Open the main HTML page in a browser, or use a local development server.
